Detailed Description

The files another computer copied, offered as virtual files.

When the application that pastes asks what there is, the whole tree is listed from the other computer, as it is at that moment. A file is fetched when it is copied.

Windows does not allow some names that other systems do. Such names are changed, names that then differ only in case get a number, and entries whose path is too long for the clipboard are left out with all they hold. Requests to the other computer always use the original names.

Detailed Description

Writes the clipboard on a thread of its own, files of other computers included.

Files copied on another computer are put on the clipboard as virtual files: the application that pastes, usually Explorer, asks for the descriptions and contents of the files through COM, and that may take as long as the other computer takes to answer. The calls arrive on the thread that put the data on the clipboard, so that thread is not the one that runs the event queue, which has to keep handling the network meanwhile.

Every change of the clipboard goes through that thread, in the order they were asked for: a later clipboard can never be overtaken by an earlier one. What is put on the clipboard is marked as Deskflow's, so that the computer does not take it for something the user copied.

Detailed Description

The files this computer currently offers to other computers.

Remembers which local files and directories were copied to the clipboard, so that requests from another computer can be mapped back to local paths. Local paths never leave this class: other computers only see the names in the ClipboardFileList and refer to a file by the identifier of the list, the index of a top level entry and a path below it.

Not thread safe, used from the thread that runs the event queue.

◆ offer()

ClipboardFileList deskflow::FileOfferRegistry::offer ( const std::vector< std::string > & paths)

Offer files.

Makes paths (absolute local paths, UTF-8) the current offer and returns the list to tell other computers. Paths that do not exist, links and special files are left out. The returned list has no entries if nothing can be offered, also when there are more paths than a list may have. Offering the same unchanged files again returns the same list with the same identifier.

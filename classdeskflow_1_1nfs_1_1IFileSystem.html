Detailed Description

The files a Server makes available.

Called from the threads of the server, several at a time. A call may block while it waits for data, but should answer with Status::TryLater rather than keep the system waiting for long.

List a directory, without the entries for the directory itself and the one above.

Returns at most limit entries, starting with the one at position first. complete tells that the last entry of the directory is among them. version changes whenever what the directory holds changes: a position is one in the directory of that version.

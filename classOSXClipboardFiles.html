Detailed Description

The copied files part of the macOS clipboard.

Files copied on this computer are read from the pasteboard as paths. Files copied on another computer are shown on a volume and put on the pasteboard with their paths there. Every method is called on the thread that runs the event queue and returns without waiting for the volume.

◆ put() [1/2]

bool OSXClipboardFiles::put ( const deskflow::ClipboardFileList & list)

Put the files of another computer on the pasteboard.

Returns false if none of them can be shown, the pasteboard is not changed then. The files replace what else the clipboard holds: an item on the pasteboard is a file or something else. The system looks at the files while they are put there, which the volume answers from list.

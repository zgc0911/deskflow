## 做法

- 三个发现切片各一个审核代理，Opus，逐文本只读审核，用时约 51 分钟。
- 每条发现要附文件和行、原文摘录、触发条件。证据不全的记为疑点。
- 主会话通读三份报告，逐条对照代码核实；高级别的也由主会话核实，没有另派复核代理。
- 两条依赖 Qt 在 Windows 上的内部行为（R01、R02），主会话按报告引的 Qt 6.12.0 源码行核对。修复时在 CI 的 Windows 上加了用例，实测确认。
- 修复的验证：
  - 每条修复都补了用例，下表写用例名。标「Windows CI」的只在 CI 的 Windows 上跑。
  - 能在本机跑的修复做了变异检查：在隔离的临时副本里去掉修复，对应用例必须失败。传输层 T1 到 T8、Mac 端 U1 到 U8 共 16 项，每项都失败了。
  - 只能在 Windows 上跑的修复没做变异检查：CI 只在推送 master 时运行，又不能开 PR。这些由主会话对照 diff 逐条核对。
  - 没有单元测试的几条（R06、R12、R14、R26 和 R17 的一部分）也由主会话对照 diff 核对。

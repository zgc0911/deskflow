# 验收：剪贴板复制文件，两台电脑实测

- 日期：2026-11-27
- 状态：待你执行。
- 依据：见文末。

## 给你的步骤

共 9 步，约 35 分钟，其中下载和安装约 10 分钟。

两台电脑都换成新版，然后在两台之间来回复制几次文件。每步做完对照「应该看到」。都对就回我「全部正常」；有不对的，回「第 N 步不对」和你看到的情况。

第 2 步要在 Mac 前用它自己的键盘鼠标做：退出旧版那一刻起键鼠共享会断开，到新版连上为止。后面的步骤都可以坐在 Windows 前，用 Deskflow 把光标移到 Mac 上操作。

1. **Windows 装新版。** 在 Windows 上用浏览器打开 <https://github.com/zgc0911/deskflow/actions/runs/45997641817>（要登录 GitHub），在页面下方「Artifacts」里下载 `package-deskflow-windows-2022-x64`。解压后双击 `deskflow-continuous-win-x64.msi`，一路按默认安装。弹出「Windows 已保护你的电脑」时，点「更多信息」，再点「仍要运行」。
   → 安装完 Deskflow 照常启动，服务端在运行；Mac 上的旧版照样能用键鼠共享。
2. **Mac 换新版。** 在 Mac 前，用 Mac 的键盘鼠标：
   1. 点菜单栏的 Deskflow 图标，选「退出」。
   2. 打开访达，按 ⇧⌘H 到个人文件夹，打开「Deskflow-new」，把里面的 Deskflow 拖到左边栏的「应用程序」。提示已有同名项时选「替换」。
   3. 打开「应用程序」里的 Deskflow。提示需要辅助功能权限时，打开「系统设置 → 隐私与安全性 → 辅助功能」：先选中列表里已有的 Deskflow，点「−」删掉；再点「+」，选「应用程序」里的 Deskflow，打开它的开关。还连不上的话，退出 Deskflow 再打开一次。

   → Mac 上的 Deskflow 连上 Windows，从 Windows 移动鼠标能进到 Mac，键盘也能用。
3. **Mac → Windows，一个文件夹，带 1 GB 的大文件。** 在 Mac 访达里打开个人文件夹，选中「DeskflowTest」，按 ⌘C。光标移回 Windows，在资源管理器里打开「桌面」，按 Ctrl+V。拷贝期间把光标在两台电脑之间来回移几次，在 Windows 上随便打几个字。
   → 出现资源管理器的复制进度窗口。完成后 Windows 桌面上有「DeskflowTest」文件夹，里面有 big.bin（1 GB）、small.txt、中文名.txt、empty.txt、「空文件夹」和「folder」，folder 里还有两层子文件夹。拷贝期间光标和键盘不卡。
4. **在 Windows 上打开 small.txt 和 中文名.txt。**
   → 中文正常显示，没有乱码。
5. **Windows → Mac，同一个文件夹。** 在 Windows 桌面选中刚粘过来的「DeskflowTest」，按 Ctrl+C。光标移到 Mac，在访达里打开「桌面」，按 ⌘V。拷贝期间同样来回移动光标、打几个字。
   → 访达显示拷贝进度。完成后 Mac 桌面上有「DeskflowTest」，内容和第 3 步一样。拷贝期间光标和键盘不卡。文件内容由我核对。
6. **Mac 桌面上的文件 → Windows。** 在 Mac 桌面的「DeskflowTest」里选中 small.txt，按 ⌘C。回到 Windows，在资源管理器里任选一个文件夹，按 Ctrl+V。
   → Mac 上弹出「“Deskflow”想访问“桌面”文件夹中的文件」，Windows 上这次粘贴失败或一直在等。到 Mac 上点「允许」，回 Windows 再粘贴一次，small.txt 出现。
7. **只按你的权限读文件。** 在 Windows 资源管理器里打开 `C:\Windows\System32`，找到「config」文件夹，只单击选中它，不要双击打开，按 Ctrl+C。光标移到 Mac，在访达里打开「桌面」，按 ⌘V。
   → 访达报错，粘不出这个文件夹里的文件。桌面上可能留下一个空的 config 文件夹，删掉即可。这个文件夹平时只有管理员能打开，Deskflow 也只按你自己的权限读文件。
8. **关掉开关。** 在 Windows 的 Deskflow 主窗口点「配置服务器」，切到「高级」，取消勾选「通过剪贴板共享复制的文件」，点「保存」。英文界面上依次是 Configure Server、Advanced、Share copied files through the clipboard、Save。然后：
   1. 在 Windows 上复制 DeskflowTest 里的 small.txt，光标移到 Mac，在访达里按 ⌘V。
   2. 在 Windows 上随便复制一段文字，光标移到 Mac，在备忘录里按 ⌘V。
   3. 回到 Windows，把这个勾选框勾回去，点「保存」。

   → 第 1 小步粘不出文件。第 2 小步文字照常粘贴。勾回去以后，在 Windows 上复制 small.txt、到 Mac 访达里粘贴，又能粘出来。
9. **传到一半断开。** 在 Windows 上复制 DeskflowTest 里的 big.bin，光标移到 Mac，在访达里打开个人文件夹，按 ⌘V。进度走到一半左右时，回到 Windows，在 Deskflow 主窗口点「停止」。看一眼 Mac 的屏幕，然后在 Windows 上点「启动」。
   → 点「停止」后几秒内，Mac 上的访达报错并停下，个人文件夹里没有留下半截的 big.bin，Mac 上的 Deskflow 没有崩溃。点「启动」后 Mac 重新连上，键鼠共享恢复。

做完以后两台电脑可以继续用新版。想换回正式版：Windows 上用官网的安装包重新安装；Mac 上把官网下载的 Deskflow 拖进「应用程序」替换，同样要重新给辅助功能权限。测试文件夹 DeskflowTest 我在验收结束后删掉，Windows 桌面上那份请你自己删。

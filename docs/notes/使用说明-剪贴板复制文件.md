# 使用说明：通过剪贴板复制文件

更新于 2026-11-27。Mac 这一端已经做好，Windows 那一端还在做，做好后在这里补上 Windows 的用法。现在没有需要你决定的事。

## 它做什么

在一台电脑上复制文件或文件夹，到另一台电脑上按粘贴，文件就传过来。

- 文件在你按下粘贴时才传，只复制不粘贴不会传任何东西。
- 粘贴时显示系统自己的拷贝进度。Mac 上是访达的拷贝进度窗口。
- 文件多大都可以，传大文件时键盘鼠标照常能用。
- 文件夹连同里面的所有内容一起传。

## 在 Mac 上粘贴别的电脑复制的文件

在访达里按 ⌘V，和粘贴本机的文件一样。

- 别的支持粘贴文件的程序一般也能用，但目前只在访达里实测过。别的程序第一次这样粘贴时，系统可能弹框问是否允许它访问「网络宗卷」，点「允许」即可。
- 剪贴板里有文件时，Mac 上只放文件。同一次复制里如果还带了文字、网页或图片，这些不会出现在 Mac 的剪贴板上。
- 名字太长的文件放不过来：Mac 上一个名字最多 255 个字节，大约 85 个汉字。这样的文件会被跳过，其他文件照常粘贴。

Deskflow 运行期间，Mac 上一直挂着一个看不见的只读磁盘，别的电脑复制的文件通过它交给访达。访达里不显示它，也不用管它。Deskflow 退出时会卸掉它。如果 Deskflow 意外退出，下一次有程序去访问它时，系统会在大约一分钟后自动卸掉；下次启动 Deskflow 时也会清理。

Deskflow 退出时，剪贴板上如果还是别的电脑复制的文件，会被清掉：退出以后这些文件粘贴不了。退出前你在 Mac 上自己复制的内容不受影响。

## 从 Mac 复制文件到别的电脑

在访达里按 ⌘C，到另一台电脑上粘贴。

- 文件夹里的符号链接不传，它们可能指向文件夹以外的地方。替身是普通文件，照常传。
- 文件夹里有打不开的子文件夹时（比如属于别的用户），粘贴到那里会报错，不会粘出一个空文件夹。

如果复制的是「桌面」「文稿」「下载」里的文件，或者网络盘、U 盘上的文件，Mac 第一次会弹一个授权框，比如「Deskflow 想访问桌面文件夹中的文件」。每个位置只弹一次。

这个框在你于另一台电脑上按下粘贴时才弹出，那时你人在另一台电脑前：

1. 切回 Mac，点「允许」。
2. 回到另一台电脑，再粘贴一次。

30 秒内没点的话，那一次粘贴会失败，点了「允许」之后重新粘贴即可。

### 事先开好权限，就不会弹框

二选一：

- **只开用得到的位置**：打开「系统设置 → 隐私与安全性 → 文件与文件夹」，找到 Deskflow，打开「桌面文件夹」「文稿文件夹」「下载文件夹」「网络宗卷」「可移除的宗卷」中你会用到的几项。Deskflow 要先弹过一次框，这里才会列出它。
- **一次开全**：打开「系统设置 → 隐私与安全性 → 完全磁盘访问权限」，点「+」，选「应用程序」里的 Deskflow，然后打开它旁边的开关。

装了新版本的 Deskflow 以后，这些权限可能要重新开：在列表里把 Deskflow 删掉，再按上面的步骤加一次。辅助功能权限也是一样。

macOS 不允许安装程序替你打开这些隐私权限，只能由你在系统设置里打开。

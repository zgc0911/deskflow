Detailed Description

Mounts the files that other computers have copied as a read-only volume.

A program that pastes files wants paths. The volume gives it paths to files that are still on another computer: the NFS client of the system mounts a server that runs inside this process and answers from an OSXRemoteFileSystem. This takes no kernel extension and no administrator rights, and nothing outside of this computer can reach the server.

Mounting, checking and unmounting happen on a thread of their own, so that the thread that runs the event queue never waits for the mount command or for the volume. The volume is mounted as soon as the object is made, and mounted again if it goes away. Finder does not show it. If this process dies the system unmounts it a minute after something next tries to use it, and the next process that makes a volume in the same directory cleans up.

virtual bool IMSWindowsVirtualFileReader::read ( void * buffer,
uint32_t size,
uint32_t & bytesRead )
pure virtual

Read file contents.

Reads up to size bytes into buffer, blocking until at least one byte is available or the end of the file is reached. bytesRead is zero at the end of the file. Returns false if the contents can not be read.

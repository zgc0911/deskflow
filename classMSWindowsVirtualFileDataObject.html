Detailed Description

Clipboard data object that offers files which are transferred when pasted.

Exposes the shell formats CFSTR_FILEDESCRIPTORW and CFSTR_FILECONTENTS. The application that pastes (usually Explorer) reads each file through an IStream and writes it to the destination itself, showing its own progress.

Detailed Description

A read-only NFS version 3 server for the loopback interface.

Lets the system mount an IFileSystem as a volume, without any kernel extension: the system's own NFS client connects to this server over TCP on 127.0.0.1. Implements the MOUNT and NFS programs on one port, as far as a read-only mount needs them.

Only the mount this process sets up is meant to succeed. The handle of the root directory is given once, to the first client that knows the export path. File handles can not be guessed, and those of one server mean nothing to another: a volume that is mounted again gets new ones.

Detailed Description

Shares the files on the clipboard with other computers.

One object serves both directions. For files copied on this computer it keeps the list that other computers are told about and answers their requests for listings and contents. For files copied on another computer it offers a blocking interface to list directories and read files, which the platform specific paste code uses when the files are actually pasted.

Unless noted otherwise methods must be called on the thread that runs the event queue. All sending and receiving happens there, in small pieces, so that input events keep flowing while a file is transferred.
